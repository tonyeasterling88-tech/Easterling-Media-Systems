Systems Note: Let the Home Page Set the Pace

Draft: 2026-08-17 · Author: Tony Easterling

A site can contain real work and still leave visitors unsure where to begin. The current Easterling Media & Systems work has been focused on that first moment: reshaping the home page into an editorial workshop and clarifying the direction for a Signal Dispatch newsletter archive. Both changes are about giving the active work a more useful order.

Start with the work that is moving

An editorial home page has a different job than a complete archive. It should orient someone quickly toward the builds, writing, and systems that are active now, then make the next path obvious. That lets the archive remain available without making every visitor do the sorting before they can understand what the site is for.

Give recurring writing a home

Signal Dispatch needs an archive that treats each issue as part of an ongoing record, not a one-time announcement. The newsletter infrastructure already supports drafting, review, and first-party publishing; the archive direction adds a clearer reader-facing place for that work to accumulate. Distribution is more useful when people can return to it later.

Lesson learned

Visibility is a sequencing problem. The home page does not need to explain every project at once. It needs to set the pace: show what is moving, offer a clear next step, and let the deeper archive support the people who want to keep going.
